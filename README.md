# homebrew-clipper4mac

Homebrew tap for [Clipper](https://github.com/kkrishnan90/Clipper4Mac), a native macOS clipboard manager with a Rust storage engine.

```sh
brew tap kkrishnan90/clipper4mac
brew install --cask clipper4mac
```

Requires macOS 14 Sonoma or newer. The cask is updated automatically by Clipper's release workflow; please file issues in the [main repository](https://github.com/kkrishnan90/Clipper4Mac/issues).
