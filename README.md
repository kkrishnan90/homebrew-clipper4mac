# homebrew-clipper

Homebrew tap for [Clipper](https://github.com/kkrishnan90/clipper), a native macOS clipboard manager with a Rust storage engine.

```sh
brew install --cask kkrishnan90/clipper/clipper
```

Requires macOS 14 Sonoma or newer. The cask is updated automatically by Clipper's release workflow; please file issues in the [main repository](https://github.com/kkrishnan90/clipper/issues).
